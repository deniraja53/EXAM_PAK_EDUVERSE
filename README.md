# EXAM EDUVERSE | Adventure Learning Game

**Petualangan Belajar EXAM EDUVERSE.** Game edukasi interaktif 2D berbasis petualangan platformer dengan dukungan **Mode Guru** untuk pengelolaan bank soal (PDF/DOCX), distribusi *Question Box*, generator **Google Apps Script (`Code.gs`)**, dan sinkronisasi ke game maupun Google Sheets.
